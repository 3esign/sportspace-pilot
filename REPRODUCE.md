# SportSpace 0.30 reproducibility

Run `node tools/research-site-data-v030.cjs` in this folder to regenerate the displayed research dataset byte-for-byte from the three included v0.25 scientific outputs. Node standard library only; no network or new dependencies.

For independent reconstruction of the scientific calculations, extract `research/SportSpace_ICSIE_2026_submission.zip` into a separate directory and follow its REPRODUCIBILITY.md. The archived v0.29 scientific package and manuscript are immutable here. Website 0.30 changes layout and presents already-computed results; it does not change numerical models.

Sources, temporal/spatial support and licences: DATA-LICENSE.md, methodology dialog and final paper. This package does not contain a live monitoring service, validated walking navigation, restricted station transcriptions, correspondence or API credentials.
