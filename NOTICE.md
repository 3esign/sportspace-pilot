# SportSpace E01 notice

Research team: Semir Poturak and Prof. Dr. Amra Tuzović.

This is an experimental research interface built from a technical working window, synthetic origin points, an OpenStreetMap-derived walking baseline, and a five-candidate public-source verification sample.

Two candidates have an independently documented operating or access regime. No candidate has been checked on site. The interface does not establish current public access, physical condition, population demand, health effects, or an official planning priority.

Source registry snapshot: 2026-09-19. Method run: `method_run_002`.
