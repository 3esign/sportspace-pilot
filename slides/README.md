# SportSpace — ICSIE 2026 conference slides

Self-contained HTML slide deck for the paper *SportSpace: Spatial Evidence for Planning Active Urban Environments in Ilidža–Stup* (Poturak & Tuzović, University of Travnik, Faculty of Technical Sciences).

- Open `index.html` in any browser; no build step, no network, no external libraries.
- Keys: arrows / Space / PgUp / PgDn navigate, `F` fullscreen, `N` speaker notes, `O` overview, `?` help. Swipe on touch. Each slide has a URL hash (`#9`).
- Print to PDF with Ctrl+P (1920×1080 pages).
- Figures are the published v0.26/v0.27 paper figures; all numbers are taken from the final manuscript and its verified outputs.

Public URL: https://3esign.github.io/sportspace-pilot/slides/
